## 🚀 快速开始

1. 下载 [Releases](../../releases) 中最新的 `lovelife-vX.Y.Z-win64.zip`
2. 解压到任意目录（如 `D:\lovelife`，**建议纯英文路径**）
3. 双击 **`lovelife.bat`** 启动（Windows 自带 Edge/Chrome 即可，**无需安装 Python**）

> 软件以本地服务方式运行在 `127.0.0.1:8765`，以独立窗口打开；关窗 10 分钟后自动退出（期间再开秒开）。

## ❓ 常见问题

| 现象 | 解决 |
|------|------|
| 杀毒软件拦截 exe | 未签名程序常见误报：在杀软隔离区恢复并添加信任（数据不受影响） |
| 双击 bat 无反应 / 页面打不开 | 先确认已**完整解压**（勿在压缩包内直接运行）；冷启动约 3-4 秒，稍候再刷新 |
| 弹出 Failed to load Python DLL | 杀软扫描临时文件所致：点确定后重新双击 bat，一般第二次正常；长期解决=把安装目录加入信任区 |
| 一键更新后重启异常 | 更新脚本自举特性：本次异常是上一版脚本的最后一跳遗留，再更新一次即归新流程；或手动解压 zip 覆盖（数据不动） |
| 想换电脑 | 复制整个安装目录（含 data\）到新电脑即可 |

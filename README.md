## 🚀 快速开始

1. 下载 [Releases](../../releases) 中最新的 `lovelife-vX.Y.Z-win64.zip`
2. 解压到任意目录（如 `D:\lovelife`）
3. 双击 **`lovelife.bat`** 启动（需要 Windows 自带的 Edge 或 Chrome）
4. 选择账号，开始记录

> 首次启动会自动创建 `data\` 文件夹存放你的数据。**请勿将 `data\` 分享给他人。**

## 🔄 更新

- **应用内更新**：设置 → 检查更新 → 一键更新（自动下载、替换程序、保留数据）
- 启动时自动检测新版并提示

## 💾 数据与迁移

```
<数据根目录>\（默认 data\，可在设置中修改）
├── accounts.json
└── <账号>\  items/outfits/food/events.json + images\
```

- **整包迁移**：拷贝整个文件夹到新电脑，双击 bat 即用
- **备份**：设置 → 导出备份包（.tar.gz）/ 从备份恢复
- **升级兼容**：数据带 schema 版本号，自动迁移

## 🛠️ 技术架构

- **前端**：原生 HTML/CSS/JS（无框架依赖），macOS 浅色风格
- **后端**：Python 本地 HTTP 数据服务，PyInstaller 打包为免安装 exe（端口 8765）
- **抠图**：u2netp（ONNX）本地推理 + onnxruntime-web，离线可用
- **存储**：JSON 分文件 + images 图片夹，可读可迁移

## 📦 从源码构建

```bash
# 打包发布 zip
python release.py

# 重编服务 exe
python -m PyInstaller --onefile --noconsole --name lovelife-server app/serve.py
```

## ❓ 常见问题

**双击 bat 没反应？** 确认 `lovelife-server.exe` 未被杀软拦截；或安装 Python 后重试。也可用 Edge 打开 `http://127.0.0.1:8765`。

**国内下载慢？** 应用内更新已内置镜像加速；手动下载可使用 ghproxy 等代理前缀。

**数据安全吗？** 纯本地存储，程序不联网上传任何数据。更新检查仅访问版本清单文件。

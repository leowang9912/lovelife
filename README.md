## ✨ 功能总览

| 模块 | 能力 |
|------|------|
| 💰 我的钱袋 | 记账流水（日期分组+每日小计）、精选收支分类与彩色图标网格、人民币大写、账户余额与余额记录快照、账单导入导出 |
| 📊 我的统计 | KPI 资产驾驶舱、收支统计/走势/分类统计/日均/收支热力（周/月/年切换）、资产走势、预算进度、cost per wear、临期提醒、吃灰预警…栏目可排序/开关/调宽 |
| 🎮 我的数码 | 设备+游戏合并管理，日均成本/折旧/每小时成本自动算，配件挂靠、维修出售流水 |

| 💄 我的生活 | 美妆洗护三层分类，使用次数流水（可删单条）、PAO 临期、空瓶回购、妆容组合 |

| 🔍 全局搜索 | 顶部搜索栏 + Ctrl+K，跨物品/穿搭/美食 |
| 👤 多账号 | 数据完全隔离，启动页点头像即进，预设头像库 |

## 💰 v1.1.0 亮点：我的钱袋

- **记一笔**：支出 / 收入 / 转账分段，一级分类胶囊 + 二级分类彩色图标网格点选，金额输入实时转**人民币大写**；默认不区分账户（不记余额），可选具体账户
- **精选收支分类体系**：支出 10 大类 79 个二级（食品餐饮 / 购物消费 / 出行交通 / 居家生活 / 休闲娱乐 / 文化教育 / 健康医疗 / 送礼人情 / 宠物 / 其他支出）+ 收入 11 类，内置 87 枚彩色分类图标
- **词条自动同步**：记「手机数码 / 服饰运动 / 个护美妆」等分类的账单，自动在「我的数码 / 我的衣橱 / 我的生活」生成对应词条（名称、金额、日期互通，同名自动合并）；**正餐账单自动进美食日历**（餐别自动映射）
- **账单导入导出**：支持支付宝账单 CSV、微信支付账单 CSV、通用模板 CSV、其他记账 App 导出文件；导入前预览识别结果、重复自动去重、批次可整批撤销；账单可导出 CSV（Excel 直开）
- **账户与余额记录**：多账户余额自动增减、账户间转账；可记录任意时间点的账户余额快照（对账），「资产走势」统计结合流水自动倒推每日资产曲线
- **使用周期**：物品停用可补停用时间，日均使用成本等使用类指标自动冻结为固定值（已使用 X 天 / 共使用 X 天 / 已停用）

## 🚀 快速开始

1. 下载 [Releases](../../releases) 中最新的 `lovelife-vX.Y.Z-win64.zip`
2. 解压到任意目录（如 `D:\lovelife`）
3. 双击 **`lovelife.bat`** 启动（需要 Windows 自带的 Edge 或 Chrome）
4. 选择账号，开始记录

> 首次启动会自动创建 `data\` 文件夹存放你的数据。**请勿将 `data\` 分享给他人。**
> 无需安装 Python，解压即用；杀毒软件首次可能拦截未签名的 `lovelife-server.exe`，选择“信任/放行”即可（详见包内「首次使用说明.txt」）。

## 🔄 更新

- **应用内更新**：设置 → 检查更新 → 一键更新（自动下载、替换程序、保留数据、自动重启）
- 启动时自动检测新版并提示

## 💾 数据与迁移

```
<数据根目录>\（默认 data\，可在设置中修改）
├── accounts.json
└── <账号>\  items/outfits/food/events/wallet.json + images\
```

- **整包迁移**：拷贝整个文件夹到新电脑，双击 bat 即用
- **备份**：设置 → 导出备份包（.tar.gz）/ 从备份恢复；账单可单独导出 CSV
- **升级兼容**：数据带 schema 版本号，旧数据自动迁移（含记账分类迁移）

## 📐 交互速记

- `Ctrl + K` 全局搜索
- 侧栏宽度：拖动侧栏与内容的接缝，双击恢复默认
- 「我的统计」栏目可拖动排序、调大小、整块屏蔽；同一行模块自动等高对齐
- 穿搭 / 美食日历：点已有记录直接编辑，空日期点击即新增

## 🛠️ 技术架构

- **前端**：原生 HTML/CSS/JS（无框架依赖），macOS 浅色风格，图标规范见 `docs/UI-ICON-GUIDE.md`
- **后端**：Python 本地 HTTP 数据服务，PyInstaller 打包为免安装 exe（端口 8765）
- **抠图**：u2netp（ONNX）本地推理 + onnxruntime-web，离线可用
- **存储**：JSON 分文件 + images 图片夹，可读可迁移

## 📦 从源码构建

```bash
python build_exe.py        # 构建 lovelife-server.exe
python release.py x.y.z    # 升版本号并打包发布 zip
```

依赖：Python 3.11+、PyInstaller；测试位于 `tests\`（node + python 单测）。

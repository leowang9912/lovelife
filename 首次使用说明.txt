人生管家（lovelife）· 首次使用说明
=====================================

【三步开始】
  1. 右键下载的压缩包（lovelife-vX.Y.Z-win64.zip），选择
     “解压到当前文件夹”或“解压到 lovelife”。
     ★ 重要：必须先解压！直接在压缩包窗口里双击是无法运行的。
  2. 进入解压出来的文件夹，双击 lovelife.bat。
     （首次启动约 3~5 秒，请稍等窗口出现）
  3. 选择账号（可点“记住上次账号”），开始使用。

【常见问题】

Q1：提示“lovelife-server.exe NOT FOUND / 文件不完整”
A1：两种可能：
    (1) 没有解压就双击了 —— 请先解压整个压缩包，再进文件夹运行；
    (2) 杀毒软件把主程序拦掉了 —— 打开杀毒软件的“隔离区 / 查杀记录”，
        找到 lovelife-server.exe，选择“恢复”并“添加信任 / 加入白名单”。
        360、火绒、Windows Defender 都可能误报（程序没有花钱买数字签名），
        本软件不联网上传数据，可放心恢复。
    ※ 本软件不需要安装 Python。看到相关提示不代表缺少 Python。

Q2：双击后弹出“Windows 已保护你的电脑”（SmartScreen）
A2：点击“更多信息” → 再点“仍要运行”。这是未上架应用的正常提示。

Q3：页面显示“无法访问此网站”
A3：启动约 3~5 秒后浏览器才会出页面。请先按 F5 刷新；
    若刷新无效，关掉窗口重新双击 lovelife.bat，多等几秒。

Q4：杀毒软件每次启动都拦
A4：一次性把整个安装文件夹加入杀软的“信任区 / 白名单”即可，
    以后升级更新都不会再拦。

Q5：想换台电脑用 / 换硬盘位置
A5：整个文件夹拷贝过去，解压/放置后双击 lovelife.bat 即可。
    数据都在 data 文件夹里，跟着文件夹走。建议放置到
    纯英文路径（如 D 盘 lovelife 文件夹），兼容性最好。

Q6：数据在哪？怎么备份？
A6：数据保存在安装目录的 data 文件夹（JSON + 图片）。
    备份：软件内 设置 → 导出全量备份包；
    或直接把整个文件夹拷走。

Q7：如何升级新版本？
A7：软件内 设置 → 检查更新 → 一键更新（自动完成，数据不受影响）。
    手动升级：下载新 zip，解压覆盖旧文件夹（data 不会被动）。

【我的数据安全吗】
  本软件完全本地运行，数据保存在你自己的电脑上，
  不会上传到任何服务器。更新下载仅从 GitHub 拉取程序文件。
  请勿把 data 文件夹分享给他人。

—— 有问题看 bat 窗口里的提示文字，基本都能找到原因。
